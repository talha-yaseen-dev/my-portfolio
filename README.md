## 📋 About the Project

This portfolio presents my background, skills, and projects as a web developer and
computer science student. It is fully responsive and works on desktop, tablet, and mobile screens.

## 🧩 Sections

- **Navbar** – responsive navigation with links to every section
- **Hero** – name, profile image, short intro, and a *View My Projects* button
- **About Me** – a short introduction about my education, interests, and goals
- **Education** – degree, institution, and academic details (Bootstrap cards)
- **Skills** – technical skills shown with Bootstrap badges and progress bars
- **Projects** – three projects with title, description, image, and link (Bootstrap cards)
- **Contact** – email address and a contact form (name, email, message)
- **Footer** – name, copyright, and quick links

## 🛠️ Built With

- HTML5
- Bootstrap 5 (via official CDN)
- Custom CSS (`style.css`)
- Google Fonts (Inter + Poppins)

## 📦 Bootstrap Features Used

- Responsive **navbar** with collapse toggle
- **Grid system** (`container`, `row`, `col-md-6`, `col-lg-4`)
- Components: **cards**, **buttons**, **badges**, **progress bars**, **alert**
- Utility classes: `text-center`, `mt-4`, `p-3`, `bg-dark`, `shadow`, `py-5`, and more

## 🚀 Run Locally

No build step is needed — it is a static website.

1. Download or clone the repository.
2. Open `index.html` in any web browser.

## 🌐 Deployment

Deployed as a static site on **Vercel**, connected to this GitHub repository.
Every push to the main branch automatically redeploys the site.
